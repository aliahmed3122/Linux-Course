# 🐧 Linux Course - Requirements

Before starting the Linux course, please install the following:

## 1. VirtualBox

Download and install **Oracle VirtualBox**:

https://www.virtualbox.org/wiki/Downloads

---

## 2. Ubuntu 24.04 LTS

Download **Ubuntu 24.04 LTS Desktop Image**:

https://releases.ubuntu.com/24.04.4/

> **Important:**  
> Download the **Desktop Image**, not the Server Image.
>
> For most computers, choose:
> **64-bit PC (AMD64) desktop image**

---

## 3. Linux Course

Course materials and notes are available on Notion:
